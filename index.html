VocalFX

Privacy Policy / Polityka prywatności

This document explains how VocalFX uses the microphone, voice recording files, and local settings. Dokument opisuje, w jaki sposób aplikacja VocalFX korzysta z mikrofonu, plików nagrań głosu i ustawień lokalnych.

Last updated / Data aktualizacji: 29 May 2026 • Version 2.8.0

1. Data Controller

The data controller of the VocalFX application is:

  • ForgeLabs Systems
  • Contact e-mail: contact@forgelabs.systems

2. Scope of the Application

VocalFX is an Android application that enables:

  • real-time voice processing with vocal effects (live monitor)
  • recording voice with effects into audio files (M4A)
  • playback and sharing of recordings

3. What Data is Processed

The application processes only data stored locally on the user's device:

  • microphone signal from the device's built-in microphone — requires RECORD_AUDIO permission
  • audio files containing recorded voice with effects, saved exclusively on the device in the app's private directory (Android/data/com.iwelautomatyka.vocalfx/files/Recordings/)
  • local app settings: presets, DSP effect parameters, EQ, AGC, volume settings, interface language
  • technical information necessary for the application to function on a given device

4. How Data is Used

  • running audio functions (DSP — voice effects, EQ, AGC, noise reduction)
  • recording voice on user demand into M4A files and playing them back from the library
  • saving user settings and custom presets
  • proper functioning of the application

5. Is Data Sent Outside the Device

No. The application does not send microphone signal or audio files to any external servers, clouds, or analytics services.

The application does not contain:

  • user login or account layer
  • cloud synchronization
  • remote upload panel for recordings
  • audio analytics (audio telemetry)
  • ads collecting voice data

6. Sharing Recordings by the User

The application provides an option to share recordings through Android's system mechanism (Intent.ACTION_SEND). Sharing occurs only on the user's explicit request through the "Share" button in the Library tab.

After pressing Share, the user independently selects the target application (e.g. WhatsApp, Discord, Telegram, Gmail, Google Drive). VocalFX does not select or control which application the recording will be passed to.

After passing the file to another application, the privacy policy of that other application applies.

7. Storing Data on the Device

  • Audio files and settings are stored only locally in the app's private directory.
  • This directory is accessible only to the VocalFX application — other applications do not have access to it (Android Scoped Storage).
  • After uninstalling the application, all audio files and settings are automatically removed by the Android system.

8. Automatic Deletion of Recordings

To protect device storage, the application uses a 100 MB limit on recordings:

  • when the total size of recordings exceeds 100 MB, the oldest files are automatically deleted (FIFO) until 80 MB level is reached
  • automatic deletion occurs before starting a new recording
  • the user can at any time manually delete any recording from the Library tab

9. Application Permissions

The application uses the following permission:

  • microphone (RECORD_AUDIO) — necessary for audio functions and voice recording

The application does not require permissions:

  • WRITE_EXTERNAL_STORAGE (storage takes place in the app's private directory)
  • INTERNET or other network-related permissions
  • access to contacts, location, calendar
  • access to other user files

Lack of microphone consent limits or makes audio functions unusable.

10. Hardware Requirements

  • microphone (android.hardware.microphone)
  • audio output (android.hardware.audio.output)

11. User Rights

  • obtain information about data processing
  • correct data
  • restrict processing
  • delete data processed locally by: deleting individual recordings in the Library tab, clearing application data through Android system settings, or uninstalling the application
  • contact the administrator regarding data protection matters

12. Children and Minors

The application is not dedicated to children under 13 years old. If the application is used by a minor, responsibility for compliance with local legal requirements lies with the adult (parent, guardian).

13. Changes to the Privacy Policy

This privacy policy may be updated together with the development of the application. The current version is always available at the privacy policy URL linked from the Google Play listing.

14. Contact

For privacy-related matters: contact@forgelabs.systems

2. Zakres aplikacji

VocalFX to aplikacja na Androida umożliwiająca:

  • przetwarzanie głosu w czasie rzeczywistym z efektami wokalnymi (live monitor)
  • nagrywanie głosu z efektami do plików audio (M4A)
  • odsłuchiwanie i udostępnianie nagrań

3. Jakie dane są przetwarzane

Aplikacja przetwarza wyłącznie dane przechowywane lokalnie na urządzeniu użytkownika:

  • sygnał z mikrofonu wbudowanego w urządzenie — wymaga zgody na uprawnienie RECORD_AUDIO
  • pliki audio zawierające nagrany głos z efektami, zapisywane wyłącznie na urządzeniu w prywatnym katalogu aplikacji (Android/data/com.iwelautomatyka.vocalfx/files/Recordings/)
  • lokalne ustawienia aplikacji: presety, parametry efektów DSP, EQ, AGC, głośność, język
  • informacje techniczne niezbędne do działania aplikacji

4. W jaki sposób dane są wykorzystywane

  • uruchomienia funkcji audio (DSP — efekty głosowe, EQ, AGC, redukcja szumów)
  • nagrywania głosu na żądanie użytkownika do plików M4A i odtwarzania ich z biblioteki
  • zapisu ustawień użytkownika i niestandardowych presetów
  • prawidłowego działania aplikacji

5. Czy dane są wysyłane poza urządzenie

Nie. Aplikacja nie wysyła sygnału z mikrofonu ani plików audio do żadnych zewnętrznych serwerów, chmur ani usług analitycznych.

Aplikacja nie zawiera:

  • warstwy logowania ani kont użytkownika
  • synchronizacji z chmurą
  • panelu zdalnego przesyłania nagrań
  • analityki audio (telemetrii dźwiękowej)
  • reklam zbierających dane głosowe

6. Udostępnianie nagrań przez użytkownika

Aplikacja udostępnia opcję udostępnienia nagrań poprzez systemowy mechanizm Android (Intent.ACTION_SEND). Udostępnienie zachodzi wyłącznie na żądanie użytkownika poprzez przycisk "Share" w zakładce Library.

Po naciśnięciu przycisku Share, użytkownik samodzielnie wybiera aplikację docelową (np. WhatsApp, Discord, Telegram, Gmail, Google Drive). VocalFX nie wybiera ani nie kontroluje, do której aplikacji nagranie zostanie przekazane.

Po przekazaniu pliku do innej aplikacji obowiązują zasady prywatności tej innej aplikacji.

7. Przechowywanie danych na urządzeniu

  • Pliki audio i ustawienia są przechowywane wyłącznie lokalnie w katalogu prywatnym aplikacji.
  • Katalog ten jest dostępny tylko dla aplikacji VocalFX — inne aplikacje nie mają do niego dostępu (zgodnie z zasadami Android Scoped Storage).
  • Po odinstalowaniu aplikacji wszystkie pliki audio i ustawienia są automatycznie usuwane przez system Android.

8. Automatyczne usuwanie nagrań

W celu ochrony pamięci urządzenia aplikacja stosuje limit 100 MB na nagrania:

  • gdy łączny rozmiar nagrań przekroczy 100 MB, najstarsze pliki są automatycznie usuwane (FIFO) do osiągnięcia 80 MB
  • automatyczne usuwanie zachodzi przed rozpoczęciem nowego nagrania
  • użytkownik może w każdej chwili ręcznie usunąć dowolne nagranie z zakładki Library

9. Uprawnienia aplikacji

Aplikacja korzysta z jednego uprawnienia:

  • mikrofon (RECORD_AUDIO) — niezbędny do obsługi funkcji audio i nagrywania głosu

Aplikacja nie wymaga uprawnień:

  • WRITE_EXTERNAL_STORAGE (zapis odbywa się w prywatnym katalogu aplikacji)
  • INTERNET ani innych dotyczących sieci
  • dostępu do kontaktów, lokalizacji, kalendarza
  • dostępu do innych plików użytkownika

Brak zgody na mikrofon ogranicza lub uniemożliwia korzystanie z funkcji audio.
